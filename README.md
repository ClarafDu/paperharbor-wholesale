# Paper Harbor · 外贸批发 Demo

虚构的义乌文具品牌。英文商品站用于选品和提交多商品询价，中文后台用于管理商品、跟进询盘和编辑 AI 生成的内容。价格均为美元演示价，产品图为原创 AI 生成素材。

## 本地运行

需要 Node.js 22.13 或更高版本。使用 Node HTTP、服务端 HTML、响应式 CSS 和内置 SQLite，无需安装 npm 依赖。单机演示可离线运行，数据直接保存在磁盘。Node 22 可能显示 SQLite 实验功能提示。

```sh
cp .env.example .env
# 编辑 .env，填入自己的 ADMIN_PASSWORD
npm run seed
npm start
```

打开 [英文站](http://127.0.0.1:3000/) 或 [商家后台](http://127.0.0.1:3000/admin)。首次启动也会自动初始化数据库。后台「商品管理」底部可重置，命令行等价操作是 `npm run seed -- --reset`。重置会清空询盘、恢复六件预置商品，并使旧询价清单失效。默认数据库位置为 `data/demo.sqlite`。

## AI 内容助手

默认使用离线模拟，根据中文关键词选取预设英文模板，适合网络不稳定的拜访场景。填写 `AI_API_KEY`、`AI_API_URL`（完整 Chat Completions 端点）和 `AI_MODEL` 后使用实时服务。服务需支持 OpenAI 兼容的 Chat Completions 和 JSON 输出。只提交可分享的商品资料。生成内容进入可编辑表单，点击保存后才写入数据库。联网通道需用实际供应商凭据验收。

## 测试

运行 `npm test`。测试启动临时回环 HTTP 服务和独立 SQLite，验证鉴权、目录、商品上架、MOQ、阶梯价、多商品询盘、示例邮箱限制、状态跟进、模拟 AI、编辑发布、服务重启和重置。需要本机允许监听回环端口。

## 部署

选择一台带持久磁盘的 Node 主机，以一个进程运行。将目录部署到主机，配置环境变量并运行 `npm run seed` 和 `npm start`，用进程管理器保持进程在线。

- 将 `DB_PATH` 指向持久卷中的绝对路径。备份应使用可保持 SQLite 一致性的快照或在停机时复制数据库。
- 在 HTTPS 反向代理后运行。代理保留原始 Host，启用 `PUBLIC_DEMO=1`，设置随机且至少 16 字符的 `ADMIN_PASSWORD`。公网只开放代理端口，可在代理对登录和 RFQ 提交限流。管理密码仅发给演示操作员。
- 公开演示只输入虚构姓名、公司和留言。应用由服务端限制邮箱为 example.com、example.net 或 example.org，并要求确认资料是虚构的。文本字段仍需由参与者遵守此要求。
- 无持久磁盘的环境需要先迁移数据库。应用按单实例设计，当前交付为本地 Demo。

## 三分钟现场演示

| 时间 | 页面与操作 | 展示结果 |
| --- | --- | --- |
| 0:00–0:40 | 登录后台，进入「AI 助手」。选择新商品，输入「硬壳笔记本」和「A5、96 页、牛皮纸封面」，生成。 | 英文标题、卖点、描述和 SEO 出现在编辑表单。 |

| 1:10–2:10 | 打开商品详情，输入 500 件并加入询价清单。再从目录加一件预置商品，用 Demo Buyer、Sample Retail、buyer@example.com、Canada 提交。 | 清单显示两件商品及各自数量和阶梯单价，提交后出现确认页。 |

## 交付范围

真实运行功能包括商品搜索、分类、管理、上下架、报价数量验证、RFQ、跟进和持久化。品牌、价格、示例商品和离线 AI 输出用于演示。管理端采用共享密码和 8 小时签名会话。询盘在后台查看，买家不会收到邮件。
